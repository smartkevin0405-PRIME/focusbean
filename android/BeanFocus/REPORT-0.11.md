유튜브 **앱**은 집중 잠금 중 쇼츠 차단이 켜져 있으면 기존처럼 전체 차단한다. 이번 수정에서 일반 유튜브를 허용한 대상은 삼성 인터넷 등 지원 브라우저의 웹 화면이다. 미지원 브라우저 제한 옵션은 별도로 유지한다.

## 업데이트 사용법과 남은 연결

설정의 `앱 업데이트 · 휴대폰에서 설치`를 연다. 이번 APK는 휴대폰에서 내려받아 기존 앱 위에 설치할 수 있다. 이후 고정 HTTPS APK 주소를 한 번 등록하면 같은 화면에서 새 APK를 받아 설치한다. 자동 설치·백그라운드 최신 버전 감시는 제공하지 않는다.

아직 고정 배포 서버가 없으므로 앱의 주소 입력칸은 비어 있다. 공개 게시 전 검토할 수 있도록 `BeanFocus-update-hosting-0.11.zip`에 APK·다운로드 페이지·버전 정보를 준비했다. 이 ZIP에는 소스나 서명 개인키가 없다. 공개 게시하거나 사용자가 소유한 HTTPS APK 주소를 연결해야 주소 입력 없이 업데이트를 받는 구성이 완성된다. 공개 배포는 아직 하지 않았다.

네트워크는 기존 내장 웹 화면 외에 사용자가 누른 업데이트 다운로드에 사용한다. HTTPS만 허용하고 리디렉션에도 같은 조건을 적용한다. 다운로드는 별도 스레드에서 수행하며 25MiB로 제한한다. 설치는 Android 기본 설치기가 최종 검증·확인한다. Knox·Family Link·기기 설치 제한을 변경하지 않는다.
