## 소스와 설치 버전

현재 작업 소스는 **0.15-beta (미배포)**입니다. 삼성 인터넷 쇼츠 차단을 두 방식으로 보강했습니다.

- 접근성 감지: 주소창이 숨겨지거나 화면 전환 중이어도 감지하도록 수정했습니다.
- 삼성 인터넷 광고 차단기: 삼성 인터넷이 집중콩을 차단기로 인식해 켜면 브라우저가 쇼츠 페이지와 쇼츠 재생 요청만 직접 막습니다. 삼성은 등록한 앱만 목록에 보여 주므로, 등록 전에는 개발자용 확인 모드에서만 확인할 수 있습니다.
다음 세션에서 확인할 남은 문제·검증·서명/배포 상태는 [인계 문서](android/BeanFocus/HANDOFF-2026-11-04.md)를 따릅니다.
아래는 기존에 배포한 **0.14-beta** 상태입니다. 삼성 인터넷의 문서 URL 수집과 브라우저 검사 비용을 개선했습니다.
주소 경로와 웹 노드가 모두 제공되지 않는 화면에서는 여전히 쇼츠를 구분할 수 없습니다.
유튜브 도메인만으로 일반 영상까지 차단하지 않으며 실기기 차단 성공이나 속도 향상을 보장하지 않습니다.

**0.14-beta APK를 게시했습니다.** 기존 인증서로 서명했으며 앱 ID·버전·서명·파일 해시와 실제 다운로드를 확인했습니다.
소스 테스트와 빌드는 통과했지만 삼성 실기기의 차단 동작과 속도 개선은 추가 확인이 필요합니다.
기존 앱은 삭제하지 말고, 집중 잠금이 끝난 뒤 동일 서명의 새 APK로 업데이트하세요.

- 패키지: `app.bean.focus`
- 기존 인증서 SHA-256: `5E:73:25:B0:FB:B0:AF:5D:F2:C8:0C:30:0F:0A:C8:D7:E6:E1:CC:D1:D2:3B:AE:0F:8B:6E:2B:AE:C4:B7:48:F4`
- 개인 서명키, 암호, 토큰 및 기기 사용 기록은 저장소에 포함하지 않습니다.

## 검사와 게시

`validate.yml`은 소스 변경 시 테스트와 서명 없는 APK 빌드를 수행합니다.
`publish.yml`은 `release/release.json` 변경 시 기존에 서명된 `release/BeanFocus.apk.b64`의 체크섬을 확인해 APK를 게시합니다.
게시 전 APK의 실제 앱 ID·버전·기존 인증서와 소스 리비전도 검사합니다.
새 APK와 메타데이터는 같은 버전으로 갱신해야 합니다. 소스 검증 작업에서는 서명키를 사용하지 않습니다.
